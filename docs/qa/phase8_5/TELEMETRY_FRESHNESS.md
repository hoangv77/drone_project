# Telemetry freshness

QA-03 and QA-07. Each status, land, odometry, position, GNSS, battery and failsafe stream retains a source timestamp watermark. Invalid, repeated, regressing, future and too-old observations cannot renew its lease. Accepted source age is carried into the steady-clock deadline. Snapshot freshness also checks each stream for a single discovered publisher. VehicleStatus continues to filter system and component IDs.

The explicit contract is the pinned PX4 XRCE Agent system-clock translation in microseconds, with Agent and adapter on the same synchronized host. Receipt and deadlines use a monotonic clock. Boot-time stamps from an unsynchronized source expire the old lease and remain ineligible. Reboot recovery requires new translated observations advancing past the previous watermark. A host clock rollback can require operator reconciliation. A unique writer per topic does not prove all streams came from one vehicle, so use one verified Agent/controller per isolated domain. CM5 hardware time sync and reboot/serial behavior remain required validation.
